Qual perfil escolher?

Use Turbo para uma mensagem curta em ambiente silencioso. Se a recepção falhar, tente Rápido. Com conversas por perto, Com ruído envia dados extras para recuperar perdas.

Para testar tons mais agudos, escolha uma opção de Alta frequência. Se a mensagem chegar incompleta, mantenha o receptor aberto e toque em Continuar com reparos no emissor.

Os tons de 15 a 19,5 kHz podem ser ouvidos por algumas pessoas. A recepção depende dos dois aparelhos.
